# Python MPG Fuel Economy Analysis

## Project Overview

This project analyzes the Seaborn MPG dataset using Python to explore vehicle fuel economy.

## Questions Explored

- What is the relationship between horsepower and fuel economy?
- How does fuel economy differ by country of origin?
- How has fuel economy changed over time?
- How does vehicle weight relate to fuel economy?
- How does fuel economy differ by number of cylinders?

## Tools Used

- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

## Key Findings

The analysis found several relationships within the MPG dataset. Vehicles with higher horsepower and greater weight generally had lower fuel economy. Vehicles with fewer cylinders generally achieved higher MPG, while average fuel economy increased over the model years included in the dataset.
